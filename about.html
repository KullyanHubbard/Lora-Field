Tentang LoraField

LoraField adalah sistem pertanian presisi berbasis LoRa P2P yang dirancang untuk membantu petani memantau kondisi lahan dan mengotomasi keputusan irigasi berdasarkan data sensor aktual serta prakiraan cuaca BMKG.

Tujuan Sistem

  • Memantau kelembapan tanah, suhu tanah, suhu udara, dan kelembapan udara.
  • Mengirim data dari node sensor ke gateway menggunakan LoRa P2P.
  • Menampilkan data secara terpusat pada dashboard web.
  • Mengotomasi irigasi berdasarkan threshold kelembapan tanah.
  • Membuat threshold irigasi fleksibel dan dapat disesuaikan.
  • Menunda irigasi jika BMKG memprediksi hujan dalam 3 jam ke depan.
