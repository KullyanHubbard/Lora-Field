# LoraField Project Rules

## Stack
- Frontend scaffold: React/Vite di `frontend/`
- Halaman statis lama: HTML/CSS/JS vanilla di `frontend/public/static/`
- Backend basic: FastAPI + SQLite di `backend/`
- Dark theme: background #0d1117, accent #00e676
- Root directory hanya untuk metadata proyek dan dokumentasi

## Konvensi Bahasa
- Label UI: Bahasa Indonesia
- Istilah teknis tetap bahasa asli: VWC, LoRa, MQTT, Gateway

## UI Rules
- Jangan ubah struktur sidebar
- Progress bar selalu sertakan label range (0% dan 100%)
- Badge status: gunakan warna yang sudah ada (green/yellow/red)
- Hapus data redundant — jika label sudah ada, jangan tampilkan raw code

## Coding Style
- Hindari inline style, gunakan CSS class
- Jangan ubah naming convention yang sudah ada
